
سامانه نوبت‌دهی مشاوره دانشگاهی

معرفی پروژه

این پروژه با هدف تحلیل و مدل‌سازی یک سامانه نوبت‌دهی مشاوره دانشگاهی تهیه شده است. این سامانه به دانشجویان امکان می‌دهد زمان‌های آزاد مشاوران را مشاهده کنند، نوبت مشاوره رزرو کنند، نوبت‌های ثبت‌شده خود را ببینند و در صورت نیاز نوبت خود را لغو کنند. همچنین مشاوران می‌توانند زمان‌های در دسترس خود را مدیریت کنند و مدیر سامانه مسئول مدیریت حساب‌های کاربران است.

اهداف پروژه

 شناسایی ذی‌نفعان و نیازهای آن‌ها
- نگارش پنج داستان کاربر (User Story)
- تشکیل فهرست کارهای محصول (Product Backlog)
- استخراج نیازمندی‌های عملکردی و غیرعملکردی
- رسم نمودار مورد کاربرد (Use Case Diagram)
- رسم نمودار فعالیت (Activity Diagram) برای فرایند اصلی سیستم

کاربران اصلی سامانه

- دانشجو
- مشاور دانشگاه
- مدیر سامانه

محدوده پروژه

تمرکز این پروژه بر تحلیل نیازمندی‌ها، برنامه‌ریزی چابک و مدل‌سازی سیستم با استفاده از نمودارهای UML است. در این مرحله، هدف اصلی تهیه مستندات مهندسی نرم‌افزار است و پیاده‌سازی کامل سامانه در محدوده فعلی پروژه قرار ندارد.
